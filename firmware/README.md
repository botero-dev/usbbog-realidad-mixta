# Firmware

Esqueleto inicial del código para el microcontrolador (**Arduino** o **ESP32**).

## Contenido

- `car_control/car_control.ino`: sketch "Hello World" por puerto serie.

## Carga del código

1. Abre `car_control/car_control.ino` en Arduino IDE.
2. Selecciona la placa (Arduino Uno/Nano o ESP32 Dev Module).
3. Sube el sketch.
